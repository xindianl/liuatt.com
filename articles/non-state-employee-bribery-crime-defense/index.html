涉嫌非国家工作人员受贿罪怎么办？

供应商返点、节日礼金、咨询费、干股、旅游安排或借款，是否属于商业贿赂，不能只看名称。关键是财物与岗位权限、请托事项及谋利行为之间是否存在权钱交易关系。

作者：刘信典律师首次发布：2026-08-30最后更新：2026-08-30主题：商业贿赂、三万元标准、回扣证据
直接回答

涉嫌非国家工作人员受贿罪，应先回答六个问题：行为人是否属于公司、企业或其他单位工作人员；是否利用采购、销售、审批、验收、付款、用人等职务便利；财物由谁给予、价值多少、实际归谁；是否存在具体请托；行为人是否承诺、实施或完成为他人谋取利益；财物与谋利事项能否由合同、审批、流水、聊天和业务结果相互印证。2022年最高检、公安部规定数额在三万元以上应予立案追诉，但三万元只是程序门槛，不能替代犯罪构成和证据审查。

一、非国家工作人员受贿罪要证明什么

现行刑法第一百六十三条规定，公司、企业或者其他单位工作人员利用职务便利，索取他人财物或者非法收受他人财物，为他人谋取利益，达到相应数额或情节的，依法承担刑事责任；在经济往来中违反国家规定，收受各种名义的回扣、手续费归个人所有，也依照该条处理。

完整审查至少包括：

  • 主体身份：行为发生时与单位的任职、管理、劳动、劳务或事实工作关系；
  • 职务便利：本人是否有权决定、影响采购、销售、招投标、验收、付款、人事或其他事项；
  • 财物：现金、转账、礼品、购物卡、干股、债务免除、免费服务等是否具有可计价利益；
  • 收受或索取：财物是否由本人控制，是否通过亲属、关联公司或第三方代收；
  • 为他人谋利：请托内容、承诺、实施和业务结果是否存在；
  • 对应关系：财物与职务行为之间是否形成权钱交易。

二、三万元立案追诉标准怎样理解

最高人民检察院、公安部《公安机关管辖的刑事案件立案追诉标准的规定（二）》第十条明确：公司、企业或者其他单位工作人员利用职务便利，索取或非法收受他人财物并为他人谋取利益，或者违规收受回扣、手续费归个人所有，数额在三万元以上的，应予立案追诉。

  • 三万元是立案追诉数额，不是看到三万元转账就当然定罪；
  • 多次收受能否累计，要逐笔证明财物性质、给予人、请托事项和对应关系；
  • 礼品、装修、旅游、干股、低价购房等非现金利益，需要核对实际支付、市场价值及利益归属；
  • 正常工资、借款、投资分红、折扣、佣金和私人赠与，不应仅因发生在业务双方之间就全部计入；
  • 退还、上交和代为保管的金额及时间，需要结合原始记录具体评价。

三、哪些人可能成为本罪主体

常见主体包括采购、销售、财务、仓储、工程、质量验收、门店负责人、项目经理、中高级管理人员以及实际承担单位管理职责的人员。是否签订劳动合同不是唯一标准，事实工作人员、受委托管理业务的人员也要根据任职来源、职责和权限判断。

国有单位人员不一定都属于国家工作人员；民营企业人员也不必然只适用本罪。国家工作人员身份、是否从事公务以及国有单位委派关系会影响与受贿罪的界限，应依现行刑法和具体证据审查，不能只看单位名称或持股比例。

四、“职务便利”与普通人情关系如何区分

职务便利要求行为人能够利用岗位权力决定或影响他人利益，例如选择供应商、确定价格、安排订单、验收质量、加快付款、决定录用晋升或处分单位资源。仅因同事关系、行业人脉或私人友谊帮忙，若没有利用本人职务权限，不应机械认定。

岗位说明书只是起点。还应调取审批权限、系统账号、会议纪要、邮件、签字流程、实际决策惯例和相关人员证言，查清行为人是否有决定权、建议权、审核权或能够实际影响最终结果。

五、“为他人谋取利益”是否必须实际办成

应围绕请托、承诺和职务行为进行证据审查，不能只以业务结果倒推。实践中需要查清：

  • 给予人是否提出进入供应商名单、提高价格、放宽验收、提前付款等具体请求；
  • 行为人是否承诺、打招呼、签批、推荐、隐瞒或以其他方式利用职务影响；
  • 财物给予时间是在请托前、办理中还是事项完成后；
  • 业务结果是否异常，是否偏离单位制度或正常商业条件；
  • 即使事项未最终办成，双方是否已经形成明确权钱交易约定。

正常礼尚往来与受贿的分界，不是单看是否“办成事”，而是综合双方关系、财物价值、给予背景、请托内容和职务行为判断。

六、回扣、手续费、返点和佣金怎样区分

刑法特别规定，在经济往来中利用职务便利，违反国家规定收受各种名义的回扣、手续费归个人所有，依照本罪处罚。名称不是决定因素：

  • 合同明确、公开入账并归单位所有的价格折扣或商业返利，与账外暗中给个人的回扣不同；
  • 真实提供独立服务并有合理对价、合同、发票和纳税记录的佣金，需要与无真实服务的“咨询费”区分；
  • 供应商将返点打入采购人员本人、亲属或其控制公司账户，应核对真实业务和实际归属；
  • 单位制度禁止并不当然等于构成犯罪，但可能成为判断行为隐蔽性和主观认识的证据之一。

七、礼品礼金、借款、干股和免费服务如何认定

财物不只表现为现金。购物卡、贵重礼品、车辆使用、旅游、装修、债务免除、低价交易、干股分红等可计价利益，都可能进入审查范围。但必须证明由谁实际支付、行为人获得何种利益及利益价值。

“借款”应核对借条形成时间、利息、期限、担保、催收、还款能力和实际归还；长期无约定、无催收、无归还且与请托事项紧密相连，可能被质疑为以借为名收受财物。干股则要审查是否真实出资、是否承担风险、分红来源和股权登记。不能只凭双方对款项的称呼作结论。

八、主动退还或上交财物有什么影响

退还时间和原因很重要。行为人当场拒收、发现后及时上交单位并留有完整记录，与已经控制、使用财物后因听到调查消息才退还的情形不同。应保存退款流水、上交登记、财务入账、沟通记录和见证材料。

退赃退赔、自首、坦白、认罪认罚等可能影响强制措施和量刑，但不能保证撤案、不起诉或缓刑。在收受事实、财物性质或数额存在争议时，也不应在未核对案卷前确认不准确的金额。

九、企业内部调查材料怎样依法使用

企业发现异常后，通常会调取邮箱、审批、门禁、业务系统、公司设备和财务资料，并与员工谈话。内部调查应注意：

  • 保留数据原始载体、提取时间、操作人和校验信息，避免截取片段；
  • 区分公司设备和个人设备、工作数据与个人隐私，遵守数据和劳动管理规则；
  • 谈话应自愿、完整记录，避免威胁、限制人身自由或诱导统一口径；
  • 合同、发票、报价、竞标、验收、付款和供应商资料应形成可追溯证据链；
  • 向办案机关移交时制作清单，说明来源和保管过程。

企业内部调查结论不能代替刑事证明，材料仍需依法审查真实性、合法性和关联性。

十、资金流水和电子数据怎样审查

专业审查应制作“财物—请托—职务行为—业务结果”逐笔表，列明：

  1. 给予人、收受人、实际账户控制人及双方关系；
  2. 转账或交付时间、金额、备注、现金来源和礼品价值；
  3. 对应合同、订单、投标、验收、付款或人事事项；
  4. 聊天、邮件、通话和会议记录中的具体请托；
  5. 行为人的职务权限、签批和实际影响；
  6. 退还、上交、正常借款、投资或私人往来的排除证据。

孤立转账、含糊备注或同案人口供不能替代完整证明。电子数据应保留上下文和提取过程，供应商与员工双方供述还要与客观资料相互印证。

十一、与受贿罪、职务侵占罪和对非国家工作人员行贿罪的边界

  • 与受贿罪：关键在行为人是否属于国家工作人员、是否从事公务以及利用何种职务便利，不能只按单位所有制贴标签。
  • 与职务侵占罪：非国家工作人员受贿罪通常涉及外部给予财物换取职务行为；职务侵占是利用职务便利非法占有本单位财物。虚增采购价格后侵吞差价的案件，需查清财物来源和行为结构。
  • 与对非国家工作人员行贿罪：给予财物一方为谋取不正当利益，个人数额三万元以上、单位数额二十万元以上，可能另涉刑事责任；收受方和给予方应分别证明各自主观目的和行为。
  • 与违纪及民事责任：违反企业制度、收受一般礼品可能承担劳动、民事或合规责任，但是否构成犯罪仍以刑法要件和证据为准。

十二、多人参与和企业责任怎样划分

案件可能涉及决策人、具体经办、亲属代收人、供应商员工和中间人。应逐人查明何时加入、知道什么、做了什么、控制多少财物、获得多少利益，不能把全部款项机械归责于所有涉案人员。

亲属账户收到资金不等于账户持有人当然构成共犯，需要证明其明知和参与；中间人转达请托、代收转交或从中截留，也要根据犯意联络和具体作用评价。

十三、当事人、家属或企业应准备哪些材料

  1. 拘留、取保、逮捕、搜查、扣押、冻结等法律文书；
  2. 劳动合同、任命文件、岗位说明、权限表和实际工作记录；
  3. 供应商准入、招投标、报价、合同、订单、验收和付款资料；
  4. 单位及个人账户完整流水、礼品票据、借款、投资和退还记录；
  5. 聊天、邮件、录音、通话、会议和系统审批原始数据；
  6. 佣金、咨询、返点或折扣的合同、服务成果、发票和纳税资料；
  7. 企业制度、合规培训、利益冲突申报及内部调查移交清单；
  8. 自首、坦白、退赃、谅解、认罪认罚及家庭责任等材料。

不要删除聊天、补造合同、倒签借条、转移资产或与证人统一口径。

十四、刑事律师在不同阶段重点做什么

侦查阶段通过会见核对身份、岗位、财物、请托和强制措施，依法提出取保或证据意见；审查起诉阶段阅卷制作逐笔对应表，审查三万元标准、职务便利、为他人谋利、财物价值和电子数据；审判阶段围绕主体、权钱交易对应关系、证据资格、数额和共同犯罪质证辩护。

对企业一方，律师可以协助依法固定证据、组织报案材料和跟进追赃挽损；对被调查人员及家属，可以根据案卷评估罪名边界和量刑因素。任何工作都不能承诺立案、取保、不起诉、缓刑、无罪或追回特定金额。

常见问题

收受财物达到三万元就一定会定罪吗？

不一定。三万元是立案追诉门槛，还须证明单位工作人员身份、职务便利、索取或非法收受财物，并为他人谋取利益，或者违规收受回扣手续费归个人所有。

朋友之间正常送礼会构成犯罪吗？

不当然构成。应结合双方关系、财物价值、送礼时间、具体请托、职务权限和谋利行为综合判断。

没有实际为对方办成事情会构成犯罪吗？

不能只看事项是否办成。应审查是否存在权钱交易约定、利用职务便利的承诺或行为，以及财物与请托事项的对应关系。

供应商给采购人员的折扣或返点都是回扣吗？

不一定。公开入账并归单位所有的折扣，与账外暗中给予个人的回扣不同；应核对合同、发票、账务和实际归属。

案发前主动退还财物就不构成犯罪吗？

不能一概而论。退还时间、原因、是否实际控制使用及上交记录均需审查，因被调查而退还通常不能自动否定此前行为。

企业内部调查的聊天和录音能直接定罪吗？

不能单独决定定罪。还需审查来源、原始载体、完整性和取得方式，并与业务、资金、审批及证人证言相互印证。

  • 最高人民检察院、公安部《关于公安机关管辖的刑事案件立案追诉标准的规定（二）》（第十条规定非国家工作人员受贿数额三万元以上应予立案追诉；第十一条规定对非国家工作人员行贿的相应标准）
